# Система учёта успеваемости на Windows Forms + .NET

Студенческий групповой проект: десктопное приложение для автоматизации контроля успеваемости студентов. 
Полная реализация по разработанным диаграммам (Use Case, ER, Class, Sequence).

### Взаимодействия
- Просмотр списка закрепленных учебных групп и предметов
- Выставление, редактирование и удаление оценок в интерактивном журнале (`DataGridView`)
- Персонализированный просмотр своего электронного дневника
- Отображение оценок по всем дисциплинам в виде удобной таблицы
- Управление пользователями (добавление студентов, преподавателей)
- Создание новых учебных групп и добавление предметов в учебный план

## Usage

1. **Запуск**: Открываешь решение (`GradeAccounting.sln`) в Visual Studio, выбираешь запуск главного WinForms проекта и жмёшь **F5**.
2. **Авторизация**: Вводишь логин и пароль тестового аккаунта в зависимости от необходимой роли.
3. **Преподаватель**: Выбираешь нужную группу и предмет из выпадающих списков, дважды кликаешь по ячейке студента в таблице для выставления или изменения оценки, нажимаешь «Сохранить изменения».
4. **Студент**: Сразу после входа попадаешь на главную панель, где отображается сводная таблица успеваемости и итоговый средний балл.

## Installation

1. Клонируй репозиторий:
```bash
git clone https://github.com
```
2. Открой файл решения `GradeAccounting.sln` в Visual Studio.
3. Дождись автоматического восстановления NuGet-пакетов (или восстанови вручную через PM).
4. Нажми **F5** для сборки и запуска.
